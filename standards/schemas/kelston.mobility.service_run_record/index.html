Mobility & Transit

Service Run Record

kelston.mobility.service_run_record v1.0.0 · stable · ids look like SRUN-000482

One completed run of one transit service - the unit the timetable is audited against. Run records are how the town knows its night service is real and its vehicles actually fit the riders who showed up.

Extends kelston.core.civic_record — inherited fields appear below.

Fields

FieldTypeReq.Description
operator ref · transit_line_operator required The operator that ran the service.
run_on date required The day the run was made.

passenger_count integer required How many riders boarded over the whole run.

Constraints

RuleWhat it protects
night_runs_need_a_night_operator A run in the night band belongs to an operator that offers night service.
when shift_band eq night · check operator.has_night_service eq True
riders_fit_the_fleet The largest rider carried never exceeds the fleet's clearance class.
when largest_rider_size_class present · check largest_rider_size_class lte operator.fleet_clearance_class
