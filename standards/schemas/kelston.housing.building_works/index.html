Building Works

kelston.housing.building_works v1.0.0 · stable · ids look like BWKS-000482

An organization that builds and maintains homes - a burrow-digging cooperative, a canopy framing crew, a shore-stilt yard. Building works declare what they can build as data, so matching a works to a project is a query, not a referral.

Extends kelston.core.organization — inherited fields appear below.

Fields
