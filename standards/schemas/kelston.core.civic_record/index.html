Civic Record

kelston.core.civic_record v1.0.0 · stable · abstract (no instances; exists to be extended)

The abstract base of every dated record in town. Harvest logs, clinic visits, permits, and inspection notes all extend this, which gives all of Kelston a single queryable event spine.

Fields

FieldTypeReq.Description
recorded_at datetime required When the record was made.
recorded_by ref · citizen The citizen who made the record, when one signed it.
note text A free-text remark, used sparingly - structured fields first.
