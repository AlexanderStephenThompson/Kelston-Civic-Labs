Making & Craft

Tool Pattern

kelston.making.tool_pattern v1.0.0 · stable · ids look like TOOL-000482

A registered design for a tool fitted to one size class - the same plane or loom shuttle drawn five ways, paw to wing to trunk. A pattern exists once a workshop registers the drawing, so any maker can build to it and any citizen can ask for their size by name.
